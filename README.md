# Breakout 打砖块游戏

基于 C++17 和 raylib 库开发的完整打砖块游戏，包含丰富的游戏机制和扩展功能。

## 功能特性

- **完整游戏循环**：菜单、游戏、暂停、结束、胜利等多种状态
- **关卡系统**：基于 JSON 的关卡配置，支持自定义砖块布局、每行颜色和分数
- **道具系统**：加长挡板、多球、减速球三种道具，随机掉落
- **粒子特效**：碰撞火花、烟雾、速度线等多种特效
- **主球拖尾**：运动轨迹半透明拖尾效果
- **多球支持**：道具激活后分裂为多个小球
- **存档读档**：三槽位独立存档，JSON 序列化
- **关卡编辑器**：内置编辑器，可自由创建和修改关卡
- **调试模式**：调整砖块生命值、球速、挡板速度
- **异步加载**：按 L 键模拟加载新背景和砖块颜色，不卡顿
- **跨平台支持**：Windows / Linux / macOS

## 编译与运行

### 依赖项
- CMake >= 3.10
- raylib >= 4.0
- C++17 编译器

### 编译步骤
```bash
mkdir build && cd build
cmake ..
make
./Breakout
操作说明
主菜单
↑/↓：选择选项

←/→：调节数值

SPACE：开始游戏

L：关卡选择

S：加载存档

E：关卡编辑器

D：调试模式

游戏中

SPACE：发球

P：暂停

S：保存关卡

调试模式
↑/↓：选择选项

←/→：调节数值
